# Языки программирования: лабораторные и курсовая

Учебные проекты по дисциплине «Языки программирования» (УГНТУ, группа БИЦз-22-01).

## Состав

| Папка | Работа |
|---|---|
| `labs/Lab25` | Типы данных, переменные, константы, преобразования |
| `labs/Lab26` | Арифметика, условия: треугольник, счёт матча, кратность |
| `labs/Lab27` | Массивы и циклы: последовательность, пароль, сумма массивов |
| `labs/Lab28` | `foreach`, функции: фильтр, смена знака, минимум, Фибоначчи |
| `labs/Lab29` | Строки и исключения: замена, подстрока, логины, индексы |
| `labs/Lab31` | Windows Forms: форма с кнопкой |
| `coursework/RequestRegistry` | Курсовая: учёт заявок на ИТ-поддержку |

## Требования

- .NET SDK 10.0
- Windows для проекта `Lab31` (Windows Forms)

## Сборка и запуск

```powershell
dotnet build
dotnet run --project labs/Lab25
dotnet run --project coursework/RequestRegistry
```

Проект курсовой поддерживает демонстрационный режим:

```powershell
dotnet run --project coursework/RequestRegistry -- --demo
```

## Курсовая

Консольное приложение «Учёт заявок на ИТ-поддержку» показывает возможности C#:
классы и перечисления, инкапсуляцию, LINQ, сериализацию JSON, асинхронную
работу с файлами и обработку исключений. Данные хранятся в `requests.json`
рядом с исполняемым файлом.
