# Языки программирования: лабораторные и курсовая

Шесть лабораторных работ и курсовая по дисциплине «Языки программирования»: УГНТУ, группа БИЦз-22-01, направление 09.03.03 «Прикладная информатика». Каждая лабораторная — отдельное консольное приложение, которое печатает ход решения задач; Lab31 — форма Windows Forms. Курсовая — консольная система учёта заявок на ИТ-поддержку с JSON-хранилищем и демонстрационным режимом без ручного ввода.

## Что внутри

- **Шесть лабораторных** — от типов данных до строк и исключений. Все проекты собираются из одного решения `CSharpLabsCoursework.slnx`.
- **Курсовая `RequestRegistry`** — модели заявки, репозиторий с фильтрами и статистикой, печать таблиц, сохранение и загрузка JSON.
- **Демо-режим** — `--demo` наполняет реестр шестью заявками и показывает все возможности без ввода с клавиатуры.
- **Никаких NuGet-пакетов** — только BCL: `System.Text.Json`, LINQ, `System.Threading.Tasks`.

## Курсовая

`RequestRegistry` — учёт заявок на ИТ-поддержку. Демонстрирует основные возможности C# на одном связном приложении:

- **Модель** — `Request` с `Id`, датой, автором, подразделением, приоритетом и статусом; вычисляемое свойство `ResolutionDays` помечено `[JsonIgnore]`.
- **Перечисления** — `RequestPriority` (низкий, обычный, высокий, критический) и `RequestStatus` (новая, в работе, решена, отклонена).
- **Репозиторий** — добавление, поиск, смена статуса, фильтры по статусу и приоритету, поиск по тексту, группировка по подразделениям, статистика и среднее время решения.
- **JSON** — сериализация с отступами и строками вместо чисел для enum, асинхронные `SaveAsync`/`LoadAsync`, восстановление счётчика `Id` после загрузки.
- **Меню** — шесть пунктов, проверка ввода, обработка ошибок файла и разбора JSON.

Данные лежат в `requests.json` рядом с исполняемым файлом, то есть в `bin/<Configuration>/net10.0/`. При сохранении файл перезаписывается.

## Демо-режим

```powershell
dotnet run --project coursework/RequestRegistry -- --demo
dotnet run --project coursework/RequestRegistry -- --demo --list
dotnet run --project coursework/RequestRegistry -- --demo --stats
```

| Флаг | Что делает |
| --- | --- |
| `--demo` | заполняет реестр и печатает списки, статистику, сохранение и загрузку |
| `--demo --list` | только списки: все заявки, новые, поиск «VPN», группировка |
| `--demo --stats` | только статистика и цикл сохранения/загрузки JSON |
| `--no-wait` | не ждёт нажатия клавиши в конце демонстрации |

## Требования

- .NET SDK 10.0
- Windows — только для `Lab31` (Windows Forms); остальные проекты кроссплатформенные

## Сборка и запуск

```powershell
dotnet build
dotnet run --project labs/Lab25
dotnet run --project coursework/RequestRegistry
```

Без `--demo` курсовая открывает интерактивное меню: просмотр заявок, добавление, фильтр по статусу, статистика, сохранение и загрузка JSON.

## Известные ограничения

- Лабораторной № 30 в наборе нет — нумерация идёт с пропуском.
- `Lab31` собирается только под Windows и использует фиксированный размер окна (`FixedSingle`), без масштабирования под DPI.
- Файл `requests.json` привязан к каталогу сборки: после `dotnet clean` данные пропадут вместе с `bin/`.
- Автотестов нет: результат проверяется по выводу консоли и вручную.
